WELCOME TO CLIPFORGE — WINDOWS AND MAC

Read README.md and SETUP.md for the complete beginner walkthrough.

1. Install Chrome, Python 3.11–3.13 (64-bit), and Node.js 22+.
2. Extract the entire ZIP into a permanent folder.
3. Windows: double-click Install ClipForge.cmd.
   Mac: double-click Install ClipForge.command.
4. In Chrome open chrome://extensions, turn on Developer mode,
   click Load unpacked, and select the extension folder.
5. Open ClipForge > AI & settings and fill out your own creator profile.
6. Upload a video, generate clips, review and export.

Want social posting? Visit https://aspirebuilderpro.com and see the
step-by-step social connection section in SETUP.md. A paid workspace
is optional; it is not needed to edit or export videos.
